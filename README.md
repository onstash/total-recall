# Total Recall

Total Recall is an MCP service for discovering memory capabilities and proposing memory operations to Life OS. Life OS owns memory approval and storage.

Install dependencies with `pnpm install`. Run `pnpm verify` to check formatting, lint, types, tests, and API contracts. Use `pnpm dev` to run the service locally. See `.dev.vars.example` for required configuration and `docs/` for integration details.

The commit hook checks Conventional Commit messages. Release Please creates release pull requests from commits on `main`.
